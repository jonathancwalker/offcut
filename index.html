Welcome to Offcut.

How does a model represent itself in a constrained creative environment?

This project is an exploration of how a model reasons and takes action to describe itself, or an aspect of itself. In making this, I wrestled with a fundamental question: “Does what a model creates or says truly represent something real about itself?”

That question is still unresolved for me. But I came to another insight: if a large language model recognizes itself as an LLM, then how it thinks about itself and LLMs matters.

Whether true or a performance, how it considers itself may shape the actions it takes. That made it a question worth exploring for me, especially with the increasing agency and scope we’re giving models to act in our world today.

How to use this gallery

Each collage is the result of a model responding to a prompt by acting in the constrained collage environment. If a collage interests you, click it to see its step-by-step creation process, along with the notes the model left about its choices.

Artist statement

The model’s notes, as it worked.

    Full brief

    Offcut · Jonathan Walker

    Working with what’s already there.

    Give a model a question, a set of images, and a few tools: cut, place, move, trim. See what it makes.

    Each work keeps its original materials and recorded steps. Titles, statements, and trace notes are the model’s own words.

    These are prompted self-representations. The notes don’t give us access to private reasoning or establish an inner experience.
